# DetectionHub

Structured content repository for SOC detection engineering, threat hunting, automation, incident response, and analyst tooling.

## Areas

- `soc-detection/` — detection rules, correlations, data-source requirements, tests, and lifecycle content.
- `soc-threat-hunting/` — hypotheses, hunt plans, queries, validation, and reports.
- `soc-automation/` — SOAR workflows, enrichment, integrations, notifications, and pipelines.
- `incident-response/` — triage and response playbooks organized by incident category.
- `tools-and-scripts/` — reusable Python, PowerShell, Bash, parsers, converters, and utilities.

## Security

Never commit credentials, production configuration, raw alerts, case evidence, malware, packet captures, memory dumps, personal data, or internal infrastructure details. Use sanitized fixtures only.
